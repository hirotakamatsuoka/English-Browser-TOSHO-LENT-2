# Portal Browser

Electron製のWindows用ブラウザです。ツールバー・タブバーを隠せます。

## 使い方（開発）

    npm install
    npm start

## インストーラーを作る（Windows）

    npm run dist

`dist/` に `Portal Browser Setup 1.0.0.exe` と `latest.yml` ができます。
管理者権限なしでインストールできます（ユーザー単位）。

## 自動更新の設定

`package.json` の `build.publish` の URL を、更新ファイルを置く場所に変えてください。

    "publish": [{ "provider": "generic", "url": "https://（自分のサーバー）/portal-browser/" }]

そこへ `dist/` の `Setup.exe` と `latest.yml`（と `.blockmap`）を置きます。
新しいバージョンを出すときは `package.json` の `version` を上げて、もう一度 `npm run dist` し、同じ場所に置き直します。
アプリは起動15秒後と4時間ごとに確認し、見つけたら自動でダウンロードして、再起動時（または終了時）に更新します。
GitHub Releases を使う場合は `provider` を `github` にして、`owner` と `repo` を指定します。

Chromium本体の脆弱性修正は、Electronのバージョンを上げて作り直すことで入ります。
月1回くらい `npm install electron@latest` → `npm run dist` → 配置、をするのがおすすめです。

## 画面上の操作（タブレット向け）

キーボードがなくても、すべて画面のボタンで操作できます。

| やりたいこと | 操作 |
|---|---|
| タブバーとツールバーをまとめて隠す | ツールバー右の「▴」ボタン（メニュー⋮の中にもあります） |
| 隠したあとに戻す | 画面上部中央の小さな「▾」をタップ |
| Windowsのタスクバーも隠す（全画面） | ツールバーの全画面ボタン |
| 検索・ズーム・印刷・履歴など | メニュー（⋮） |
| タブの操作（複製・ミュートなど） | タブを長押し |
| 拡大・縮小 | 2本指でピンチ |

キーボードがあるときのショートカット（Ctrl+T、Ctrl+L、F11 など）も使えます。

## 暗証番号（PIN）

初回設定の「利用時間と暗証番号」で、4〜8桁の数字を決められます（空欄なら暗証番号なし）。
暗証番号があると、次の操作で入力が必要になります（一度入力すると10分間は不要）。

- 設定画面を開く、設定を変える
- ホームのお気に入りの編集
- 閲覧データの削除、ポータルのログインやり直し

5回まちがえると30秒ほど入力できなくなります（さらにまちがえると長くなります）。
暗証番号を忘れたときは、アプリを終了して `%APPDATA%\Portal Browser\settings.json` の `"pin": {...}` を `"pin": null` にすると解除できます。
暗証番号を決める前は、だれでも設定画面から暗証番号を設定できるので、配る前に必ず設定してください。

## データの保存場所

`%APPDATA%\Portal Browser\` に、設定・履歴・ブックマーク・Cookie・Local Storage などが保存されます。
ユーザー名もここ（ローカル）だけに保存され、外部には送られません。
